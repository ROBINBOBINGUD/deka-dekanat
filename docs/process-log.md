**Решения по стеку и почему:**

| Решение | Причина |
|---|---|
| Node 24 + Express 5, без сборки клиента | до дедлайна 5 часов; нет цепочки сборки — нечему сломаться на хостинге без Docker |
| SQLite через встроенный `node:sqlite` | ноль нативных зависимостей; проверено командой `node -e "require('node:sqlite')"` → SQLite 3.53.3 |
| Сессии в БД | сервер без состояния, масштабируется по числу экземпляров |
| Без живого LLM в продукте | ключ ИИ пришлось бы хранить на сервере и ходить к API, недоступному из России |
| Название «Дека» | коротко от «деканат»; свой логотип вместо логотипа вуза |

**Решения по стеку и почему:**

| Решение | Причина |
|---|---|
| Node 24 + Express 5, без сборки клиента | до дедлайна 5 часов; нет цепочки сборки — нечему сломаться на хостинге без Docker |
| SQLite через встроенный `node:sqlite` | ноль нативных зависимостей; проверено командой `node -e "require('node:sqlite')"` → SQLite 3.53.3 |
| Сессии в БД | сервер без состояния, масштабируется по числу экземпляров |
| Без живого LLM в продукте | ключ ИИ пришлось бы хранить на сервере и ходить к API, недоступному из России |
| Название «Дека» | коротко от «деканат»; свой логотип вместо логотипа вуза |

## 19:05. Хостинг: что выяснил субагент

Субагент № 1 за 90 секунд сверил документацию площадок и вернул таблицу со ссылками на источники. Вывод: **Amvera Cloud** — деплой через `git push` в их репозиторий без GitHub и без локального Docker, сборка на их стороне, постоянный диск `/data`, бесплатный домен с HTTPS, около 70 ₽ за неделю. Запасной вариант — VPS по SSH-ключу. Что субагент честно пометил «не подтверждено»: время первой сборки, стартовый бонус, поддержку Node 24.

Отдельный субагент (web-fetch) достал точный формат `amvera.yml`: версия Node подставляется в тег образа `node:<версия>`, ветка для деплоя — `master`, постоянное хранилище монтируется в `/data`. По этим данным написаны `amvera.yml` и запасной `Dockerfile`.

**Вручную (человек):** регистрация на площадке, оплата, создание проекта, ввод пароля при `git push`. ИИ к паролям и оплате не допускается.

| Признак | Где | Исправление |
|---|---|---|

| Перенос пары показан дважды | «Сегодня» | один раз — там, откуда пара ушла |

Снимки после правок — `docs/screens/v2/`; сравнение «до и после» — в описании работы.

**Сквозной сценарий в браузере** (`scripts/e2e.py`, 17 шагов на 360 px): неверный пароль → вход → расписание → учёба → заказ справки → переписка → сотрудник берёт в работу и отмечает готовой → у студента код проверки и уведомление → публичная проверка → объявление → отмена пары → второй студент не видит чужого → пересдача → отмена заявки → выход. Первый прогон упал на шаге 9 из-за неточного селектора в самом тесте (в ленте оказалось два похожих уведомления), после правки — все 17 шагов зелёные.

**Codex (`gpt-6.2-sol`, effort high)** запущен дважды, только на чтение: дизайн-критика второй версии по шести снимкам и ревью безопасности. Первая попытка запуска упала: флаг `-i` (картинки) «съел» текст задания как имя файла — исправлено передачей промпта через stdin.

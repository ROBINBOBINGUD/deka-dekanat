## Как обновить стенд

1. Правки — в ветке `main` (эта папка), `npm test`, коммит.
2. В папке ветки деплоя (`../mgimo-dekanat-deploy`): `git merge main`, затем `git push amvera deploy:master`.
3. Проверка: `python scripts/e2e.py https://<домен>` — но только на свежей базе, сценарий создаёт заявки. Для живого стенда достаточно `scripts/shots.py`.

Пересоздать данные на стенде: в кабинете Amvera, вкладка «Переменные» — добавить `RESEED=1`, перезапустить, затем удалить переменную.

4. Открытый репозиторий: `bash scripts/publish-github.sh` (из Git Bash). Скрипт публикует копию ветки `main`, где личная почта автора заменена на служебный адрес GitHub. Ветку `deploy` публиковать нельзя: в ней пароли стенда.

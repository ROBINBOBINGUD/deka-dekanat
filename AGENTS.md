# AGENTS.md — правила для ИИ-агентов в этом репозитории

Этот файл читают Claude Code, Codex, Cursor и другие агенты перед любой правкой. `CLAUDE.md` ссылается сюда же.

## Что это

«Дека» — прототип личного кабинета студента («цифровой деканат») для конкурса MGIMO×AI Challenge. Задание: `docs/ЗАДАНИЕ.md`. Спецификация: `docs/SPEC.md`. План и статус: `docs/PLAN.md`. Журнал работы с ИИ: `docs/process-log.md`.

## Карта проекта

```
server/        Express-сервер: index.js (запуск), app.js (маршруты), db.js (схема и запросы),
               auth.js (сессии, пароли, лимит входа), schedule.js (наложение изменений), domain/*.js
public/        клиент без сборки: index.html, app.js (роутер), views/*.js, ui.js (html-шаблон, утилиты),
               styles/app.css (основа), styles/ledger.css (третья итерация дизайна), styles/staff.css
seed/          data.json (вымышленные данные), demo-accounts.json (пароли для локального запуска), seed.js.
               Пароли стенда для жюри — demo-accounts.prod.json: в основной ветке его нет, только в ветке deploy
tests/         node --test: изоляция данных, вход, заявки
docs/          задание, спецификация, журнал, скриншоты, описание процесса
scripts/       служебные скрипты (генерация аккаунтов, скриншоты, сборка PDF)
```

## Команды

- `npm install` — зависимости.
- `npm run seed` — пересоздать БД из `seed/data.json` (удаляет прежние данные).
- `npm start` — сервер на `PORT` (по умолчанию 3000).
- `npm test` — тесты на временной БД; должны быть зелёными перед каждым коммитом.

## Жёсткие правила

1. **Чужие данные недоступны.** Идентификатор пользователя — только `req.user.id` из серверной сессии. Любой запрос к данным студента фильтруется по нему. Новая ручка без такого фильтра — ошибка. Добавил ручку — добавь тест в `tests/isolation.test.js`.
2. **Только вымышленные данные.** Никаких настоящих ФИО студентов и преподавателей, оценок, номеров зачёток. Почта — только на домене `example.edu`.
3. **Секреты не в коде.** Ни ключей, ни паролей сервисов в репозитории и в браузере. Настройки — через переменные окружения. Не выводи пароли в чат и в логи.
4. **Не официальный сервис.** На экране входа и в подвале должна оставаться пометка «концепт для конкурса». Логотип вуза не использовать.
5. **Экранирование.** В клиенте данные вставляются только через шаблонный тег `html` из `public/ui.js`; `innerHTML` с сырой строкой запрещён.
6. **Мобильная ширина 360 px.** Любой экран проверяется на 360×740 до коммита: без горизонтальной прокрутки, цели нажатия не меньше 44 px.
7. **Без новых зависимостей без причины.** Сейчас их две: `express` и `helmet` (хеш паролей — встроенный в Node scrypt). Каждая новая записывается в `docs/process-log.md` с лицензией.
8. **Часовой пояс — Europe/Moscow.** «Сегодня» считается через `server/time.js`, не через `new Date()` сервера.

## Как работать

- Перед этапом перечитай `docs/ЗАДАНИЕ.md` и раздел спецификации, который меняешь.
- Один агент — одна область файлов. Параллельные агенты не правят одни и те же файлы.
- После этапа: `npm test`, запись в `docs/process-log.md` (что просили, что получилось, что ИИ сделал не так и как исправили), коммит.
- Ревью безопасности делает другой агент (Codex), не автор кода. Замечания и исправления — в журнал.
- Тексты в UTF-8 правь инструментом редактирования, а не конвейером PowerShell 5.1 (`Get-Content | Set-Content` портит кодировку).
- Деплой: ветка `deploy` = `main` + один коммит с `seed/demo-accounts.prod.json`. Обновление стенда: в папке ветки `git merge main`, затем `git push amvera deploy:master`. Ветку `deploy` в открытый репозиторий не отправлять.
